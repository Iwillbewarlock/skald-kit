# Skald 키트

스카이림 기본 메뉴처럼 보이는 어두운 UI 디자인입니다. ChatGPT, Codex, Claude, Gemini 같은 AI에게 이 폴더를 주면 자기 모드의 화면에 그대로 입힐 수 있습니다.

## 쓰는 법

1. 이 폴더를 통째로 AI에게 줍니다. ChatGPT라면 폴더를 zip으로 압축해 대화창에 올리고, Codex·Claude Code 같은 코딩 AI라면 모드 프로젝트 안에 폴더를 넣습니다.
2. 아래 문장을 그대로 붙여 넣습니다. `[ ]` 안만 자기 모드에 맞게 바꿉니다.

```
첨부한 Skald 키트의 SKALD.md를 끝까지 읽고, 그 규칙대로 [내 모드의 UI 파일 경로나 이름]에 Skald 디자인을 적용해 줘.
- 화면 문구, 기능, ID는 바꾸지 말고 모양만 바꿔.
- 마크업을 고칠 수 있으면 방법 A, 아니면 방법 B(스타일시트 덮어쓰기)로 해.
- 끝나면 SKALD.md의 "Before you finish" 목록을 하나씩 확인한 결과와, 게임 안에서 내가 직접 봐야 할 것을 알려 줘.
```

3. 결과를 받으면 `demo.html`을 브라우저로 열어 견본 화면과 비교합니다.

## 파일

- `SKALD.md`: AI가 읽는 적용 안내서(영어). 규칙, 색상 용도, 구성 요소, 마무리 점검 목록이 들어 있습니다.
- `skald-tokens.css`, `skald.css`: 화면에 넣는 스타일시트 두 개.
- `skald-tokens.json`: 같은 값을 데이터로 담은 파일. SkyUI(Flash)나 MO2 플러그인(Qt)처럼 CSS를 쓰지 않는 화면은 이 값만 가져다 씁니다.
- `assets/`: 모서리 매듭 장식과 빈 화면용 삽화(빈 화면용 삽화는 Heart of Magic 전용).
- `demo.html`: 모든 구성 요소를 한 페이지에 보여 주는 견본.

## 알아 둘 것

- CSS를 쓰는 화면(PrismaUI 같은 HTML 기반 UI, 웹 페이지, 런처)에는 전부 적용됩니다. Flash로 만든 SkyUI 메뉴에는 색과 크기 값만 옮겨 쓸 수 있습니다.
- 글꼴은 Windows 기본 글꼴 Bahnschrift를 씁니다. 글꼴 파일은 들어 있지 않습니다. 게임 안에서 글꼴이 다르게 나오면 SKALD.md의 Type 항목을 따릅니다.
- 어두운 테마(다크 모드)만 있습니다.
